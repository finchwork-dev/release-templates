# Open-source release checklist
- [ ] Version bumped (semver) in manifest and lockfile
- [ ] CHANGELOG entry (Added/Changed/Fixed/Removed), dated
- [ ] Tests and CI green on main
- [ ] README install and usage verified on a clean machine
- [ ] Breaking changes documented with migration steps
- [ ] License and third-party notices current
- [ ] Git tag signed/created, release notes published
- [ ] Package published, install from registry verified
- [ ] Docs site rebuilt, links checked
- [ ] Announcement drafted (no unverifiable claims)
